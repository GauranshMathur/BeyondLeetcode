Find the path from the root to each value with a recursive search. If either value is missing, print `none`. Both paths start at the root, and once they go to different children they never meet again, so the lowest common ancestor is the last node the two paths share. If one value is an ancestor of the other, the shorter path ends at it and it is the answer, and for equal values the two paths are the same.

Each search visits at most every node, so this takes O(n) time in the **worst case**, and O(h) space for the paths. In a binary search tree the answer can be found faster, in O(h): from the root, go left if both values are smaller than the node, go right if both are larger, and stop at the first node where they split or where one of them is found. That needs the search rule, which this Problem does not assume.
