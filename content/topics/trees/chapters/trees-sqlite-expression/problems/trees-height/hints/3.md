To read the tokens, make the root, put it in the queue, and then repeat: take the next node from the queue, read one token for its left child and one for its right. A token that is not `-` makes a new node, which joins the end of the queue. If the tokens have run out, the child is absent. `show` is the same walk, writing a `-` for each absent child and dropping the trailing `-` at the end.
