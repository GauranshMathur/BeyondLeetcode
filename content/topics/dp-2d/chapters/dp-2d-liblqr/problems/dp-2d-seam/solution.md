Keep a table `m` with the same shape as the grid, where `m[y][x]` is the cheapest total energy of a seam from the top row down to the cell at row `y` and column `x`. Copy the first row. For every later row, `m[y][x]` is `grid[y][x]` plus the smallest `m[y - 1][k]` for `k` in `x - 1`, `x` and `x + 1`, leaving out the columns that do not exist. Print the smallest value in the last row.

**Why it is right.** A seam to `(y, x)` has some cell in the row above, and that cell is one of the three neighbours. The part of the seam above it is a seam to that neighbour, and the cheapest whole seam uses the cheapest such part, so `m` is the energy of the cell plus the cheapest of the three. A seam may end anywhere in the last row, so the cheapest seam is the cheapest cell there. This is liblqr's minimum-energy map with a step of one column and no rigidity.

**Cost.** Each of the R × C cells reads at most 3 others: O(R × C) time and space in the **worst case**. Only the previous row is read, so two rows would do for the cost alone. The table is kept whole here because naming the seam needs a way back, as liblqr's `least` array shows, and because the next Problem counts seams with a second table of the same shape.
