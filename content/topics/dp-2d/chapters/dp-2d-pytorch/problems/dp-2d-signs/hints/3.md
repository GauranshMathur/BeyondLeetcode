So you count the ways to choose a group of weights that adds up to `P`. Let `table[i][s]` be the number of ways to choose among the first `i` weights so that the chosen ones add up to `s`. Each weight is either not chosen, which is `table[i - 1][s]`, or chosen, which is `table[i - 1][s - weight]`. A weight of 0 can be chosen or not at any `s`, and the two terms are both counted.
