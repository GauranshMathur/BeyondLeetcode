# Content lives in the repo and ships inside the image

Topics, Chapters, Problems, Tests, Hints, Solutions and Reference Code are files in this repository, contributed through issues and PRs, reviewed against `docs/content-standards.md`, and bundled into each release image. There is no in-app content editor. We chose this so every sentence and test is reviewed and verified by a human before it reaches a Learner, and so an Instance's content is exactly its image version. The cost: operators get new content only by upgrading, and cannot author private content without forking.
